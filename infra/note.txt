##### docker mongo setup

Mongo runs as a single-node replica set (rs0) because the outbox write needs a multi-document
ACID transaction. The replica set is initialised automatically by the "mongo-init" service in
docker-compose.yml - it waits for mongod, calls rs.initiate() once, and is a no-op on every
later start. There is nothing to do by hand.

If you ever need to look at it yourself:

docker exec -it comms-mongo mongosh "mongodb://admin:admin@localhost:27017/?authSource=admin"
rs.status()
